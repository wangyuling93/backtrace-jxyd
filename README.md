# 江西移动回程路由测试

基于 [zhanghanyun/backtrace](https://github.com/zhanghanyun/backtrace) / [ludashi2020/backtrace](https://github.com/ludashi2020/backtrace)，仅测试江西移动。

目标：`211.141.90.68`（江西移动 DNS，AS56045）

## 使用

```shell
curl https://raw.githubusercontent.com/wangyuling93/backtrace-jxyd/main/install.sh -sSf | sh
```
